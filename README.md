# Amazon-Web-Scraper
This project is a simple Amazon web scraper that tracks the price of a specific product daily and saves the data to a CSV file. It can also send an email alert when the price drops below a defined threshold.

🛠 Features
Scrapes product title and price from an Amazon product page.

Saves the data along with the current date to a CSV file.

Appends new data daily using a scheduled loop.

Sends an email notification if the price drops below a certain amount.
